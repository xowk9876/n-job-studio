# 로또 번호 생성기 업데이트 · 2026-10-31

## 사용자 동작

- 기본 `균등 무작위`: 1~45에서 중복 없이 6개를 뽑는다. 합계·홀짝·연속번호·직전 회차 점수로 후보를 다시 선별하지 않는다.
- 한 번에 생성한 1·3·5게임 사이에 같은 6개 조합을 중복하지 않는다. 개별 번호가 여러 게임에 겹치는 것은 허용한다.
- 선택 `균형 필터`: 기존 합계 100~175, 최대 2연속, 3개 이상 구간 분산 및 패턴 점수 선별을 유지한다.
- `과거 1등 당첨 조합 제외`는 기본 해제다. 선택하면 표시된 데이터 기준 회차까지 본번호 6개가 완전히 일치하는 조합만 제외한다.
- 필터는 당첨 확률을 높이지 않는다. 각 조합의 1등 확률은 1/8,145,060이다.
- 결과에 생성 당시 모드와 과거 조합 제외 기준을 표시한다. 설정이나 데이터가 바뀌어도 이미 생성된 번호는 보존한다.

## 최신 데이터

기준 회차·추첨일·공식 조회/저장 데이터 상태를 항상 표시한다. 보이는 탭에서 5분마다, 오래 닫았다가 돌아왔을 때, 네트워크 재연결 시 갱신한다. 자동 조회는 서버의 공식 API 5분 캐시를 공유한다.

사용자의 새로고침은 `/api/lotto/stats?refresh=1`로 공식 API 캐시도 갱신한다. 통계 응답은 `Cache-Control: no-store`로 CDN·브라우저의 오래된 응답을 재사용하지 않는다. 기존 요청 속도 제한을 유지한다.

요청 중 중복 호출을 막고, 20초 제한과 언마운트 취소를 적용한다. 실패 시 오류·재시도를 보여 주고 기본 생성은 유지한다. 더 오래된 스냅샷이 이미 확인한 최신 회차를 덮어쓰지 않는다. 과거 조합 제외를 선택했지만 기준 데이터를 한 번도 받지 못했다면 조용히 조건을 무시하지 않고 재시도 또는 옵션 해제를 안내한다.

이번 확인 시 공식 API·운영 API·저장 데이터가 모두 1247회(2026-10-24)로 일치해 당첨번호 원본은 변경하지 않았다.

## 검증

- 7개 번호에서 6개를 뽑는 5,040개 난수 선택 경로를 전수 검사: 가능한 7개 조합이 각각 720회로 동일하다.
- 최저·최고 합계, 6연속, 전체 홀수, 과거 당첨 조합도 기본 모드에서 허용하는지 검사한다.
- 과거 조합 제외, 게임 간 동일 조합 거부, 균형 필터 조건, 정수 난수의 모듈러 편향 제거를 검사한다.
- HTTP 실패·잘못된 응답 후 재시도, 최신 데이터 보존, 수동 조회 캐시 우회, 기본 화면 렌더링을 검사한다.
- 기존 계산기 회귀 검사와 함께 `npm test`, `npm run build`, `npm run lint`를 실행한다.

## 유지보수

생성 정책은 `lib/lotto/generator.ts`, 응답 검증은 `lib/lotto/stats-client.ts`, 새로고침 수명은 `hooks/useLottoStats.ts`에서 관리한다. 원본 회차 스냅샷은 클라이언트 번들에 포함하지 않는다. 로깅에 생성 번호나 클립보드 내용을 남기지 않는다.
