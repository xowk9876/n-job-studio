# 2026-10-31 전체 콘텐츠 점검

## 범위와 변경 이유

공개 페이지 18개(홈, 계산기 6개, 가이드 목록·본문 7개, 소개·문의·개인정보·약관 4개)의 안내 문구를 점검했다. 계산 기준과 다른 설명, 근거 없는 단정, 중복 안내를 정리했다. 계산 알고리즘과 로또 결과 행 레이아웃은 변경하지 않았다.

- 연봉: 원천징수 100% 기준, 본인 포함 가족 수와 8~20세 자녀 입력, 비과세 수당·추가 수당의 적용 범위를 명확히 했다.
- 퇴직금: 마지막 근무일, 평균임금·통상임금 비교, 연차수당과 산정 제외 기간의 미지원 범위를 설명했다. 가이드의 1,917일·92일 가정 예시를 22,007,251원으로 정정했다.
- 대출: DSR은 승인 한도가 아닌 원리금균등 역산 가정임을 표시했다. 실제 약정금리와 스트레스 가산금리를 구분하고 금리 유형·지역·경과규정 설명을 보완했다.
- 저축·ISA: 근거가 불명확한 10년 수익 전망 대신 동일 과세 대상 수익 1,000만원의 세금 예시로 바꿨다. 일반형 200만원·서민형/농어민형 400만원 및 3년·납입한도 조건을 구분했다. 계산기의 일반형 비교는 단순 세금 가정임을 표시했다.
- 전월세: 법정 전환 상한의 적용 방향, 보증금 역산의 협의용 성격, 고정 3% 비용 비교 가정을 설명했다. 전세가율만으로 안전·보증 가입을 판정하는 표현과 피해 예방률 주장을 제거했다.
- 로또: 1~3등 고정 당첨금 예시를 회차별 변동으로 바꿨다. 구매 방식별 지급처·원본 보관·세금과 수령기한 안내를 정리했다.
- 안내 페이지: 실제 localStorage 저장, 광고·호스팅·문의 정보 처리를 반영했다. 확인되지 않은 답변 기한·실시간 업데이트 약속과 경쟁 서비스에 대한 단정을 삭제했다.
- 검색·공유: 가이드 제목·설명, RSS 12항목, JSON-LD 기능 목록, 공유 이미지 문구를 본문과 동기화했다. 없는 연복리·연차수당 입력·원천징수 비율 선택·당첨금 세금 시뮬레이션 안내를 삭제했다.
