# 2026-10-31 계산·설치 업데이트

## 수정 내용

- 월 급여 소득세를 연말정산 추정식에서 공식 간이세액표 조회로 교체. 646개 구간·가족 1~11명·월 1천만원 초과 공식·월 자녀공제를 반영한다. 원천징수 선택비율은 100%다.
- 공식 PDF의 표를 `data/income-tax-2026.json`으로 추출했다. 원문 URL·개정일·확인일·SHA-256을 파일에 기록했다. 표 연속성과 공식 예제를 테스트한다.
- 휴일근로는 각 휴일 8시간 이내/초과 시간의 월 합계를 별도로 입력한다. 이전 저장값의 분할을 추정하지 않고 재입력을 알린다.
- 퇴직금은 마지막 근무일 다음 날을 법적 퇴직일로 사용해 직전 3개월을 계산한다. 평균임금은 최종 금액 산출 전 반올림하지 않는다. 저장된 날짜를 보존한다.
- 숫자 범위·유한값·실제 달력 날짜·복원 상태를 검사한다. 대출은 아주 작은 금리에서도 안정적인 현가계수를 사용한다. 입력 오류를 화면과 보조기기에 알린다.
- 로또는 연속된 회차가 모두 확보됐을 때만 최신 통계로 표시한다. 중간 회차 누락은 완전한 기존 스냅샷으로 되돌리고 기준 회차를 표시한다. 스냅샷 최신 회차를 실시간 조회 상한으로 오인하지 않는다.
- Android·iPhone·PC 바로가기 버튼을 항상 표시한다. iPhone은 Safari 수동 추가 안내, Android/PC는 지원 시 브라우저 설치 창을 사용한다. 이벤트는 취소·실패 시에도 재사용하지 않는다.
- 금융 가이드: 임차 대항력 발생일, 복권 과세최저한·수령처·기한, IRP 과세, ISA 연금전환 추가 한도, 청년도약계좌 신규 가입 종료, 통상임금 고정성 요건을 정정했다. 전세가율만으로 안전을 보장하는 표현을 제거했다.
- 하위 페이지 hreflang 중복을 제거하고 공유 이미지 실행 환경을 Node로 옮겼다. 원화 로고는 폰트 외부 요청에 의존하지 않는 SVG다.
- Node 24 타입을 맞추고 계산·저장·API 실패·설치 동작 테스트와 GitHub 검증 워크플로를 추가했다.

## 의존성 판단

운영 의존성은 알려진 취약점 0건이다. 개발 도구의 minimatch 10.2.6은 상위 패키지 범위를 지정해 11.0.1로 교체했다.
`npm audit`는 minimatch 3.1.5까지 `<11.0.1` 범위로 포함하여 개발 경로 경고 15건을 계속 보고한다.
[저자 보안 공지 GHSA-g3hv-75wg-m249](https://github.com/isaacs/minimatch/security/advisories/GHSA-g3hv-75wg-m249)는 10.2.6의 `firstPhasePreProcess`와 `optimizationLevel >= 2` 경로를 명시한다. 3.1.5 소스에는 해당 경로가 없다. 다만 감사 경고 자체를 제거하거나 전체 취약점이 0건이라고 보고하지 않는다.
구 API를 쓰는 ESLint 경로의 minimatch 3을 11로 강제 교체하지 않는다. ESLint 10·TypeScript 7은 현행 React ESLint 플러그인/TypeScript ESLint의 호환 범위를 벗어나므로 유지한다.

## 검증

```sh
npm ci
npm test
npm run build
npm run lint
npm audit --omit=dev --audit-level=moderate
```

CI는 배포를 직접 수행하지 않는다. 기존 GitHub main → Vercel 배포 연결을 유지한다.
실제 보험료의 신고 보수·연말정산·휴직 등 법정 예외는 계산기 기본 가정과 다를 수 있다.
홈 화면 설치는 사용자가 자신의 기기에서 브라우저의 최종 추가/설치를 선택해야 한다.
